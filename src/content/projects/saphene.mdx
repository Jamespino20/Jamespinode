# Saphene — Clarity Through Evidence

Saphene verifies claims against recorded evidence before they become memory.

## Problem

Agent memory drifts. Assertions get repeated until they feel true.

## Approach

- Claim ledger with explicit status
- Evidence scope per claim
- Fail-closed validation: no evidence, no promotion

## Status

Completed hackathon project. See repository for implementation.
